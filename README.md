### 🔩 Embedded Software Enthusiast

> *I started at the register level — writing flight-critical firmware for avionics systems, tuning PID controllers on oscilloscopes, designing PCBs for 17A power systems, and building CAN/SPI/I2C/UART drivers from scratch. That embedded-first mindset drives everything I build today.*

At **Ducom Aerospace**, I developed bare-metal C firmware on ARM Cortex-M4 for avionics thermal management — FreeRTOS task scheduling, DMA-driven sensor acquisition at 1kHz (40% CPU load reduction), closed-loop servo control, and multi-layer PCB design. Every line of code ran on real hardware with zero tolerance for failure.

That foundation carries into everything I build — whether it's an IoT gateway protocol, a backend API, or a cloud deployment pipeline. Systems that are **efficient, deterministic, and reliable** because they were designed by someone who started at the metal.
