### 🔩 Embedded Software Enthusiast

I started at the register level.

Flight-critical firmware on **ARM Cortex-M4** at Ducom Aerospace — PID thermal controllers tuned on oscilloscopes, FreeRTOS task scheduling with DMA-driven sensor acquisition at **1kHz**, CAN/SPI/I2C/UART drivers written from scratch, and multi-layer PCB design for **17A power systems**. Every line of code ran on real hardware with zero tolerance for failure.

That embedded-first mindset carries into everything I build — IoT gateways, backend APIs, cloud infrastructure. Systems that are **efficient, deterministic, and reliable** because they were built by someone who started at the metal.
